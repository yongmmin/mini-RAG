# 계정 관리

## 비밀번호 정책

하늘창 계정의 비밀번호는 12자 이상이어야 하며, 영문 대문자, 영문 소문자, 숫자, 특수문자 가운데 세 종류 이상을 섞어야 합니다. 아이디나 이메일 주소와 같은 문자열은 비밀번호에 포함할 수 없습니다. 비밀번호는 90일마다 바꾸도록 안내되며, 최근에 사용한 비밀번호 5개는 다시 쓸 수 없습니다. 비밀번호를 잊어버렸다면 로그인 화면의 "비밀번호 재설정"을 눌러 등록한 이메일로 재설정 링크를 받을 수 있고, 이 링크는 발송 후 30분 동안만 유효합니다.

## 로그인 잠금

비밀번호를 5회 연속 잘못 입력하면 계정이 30분 동안 잠깁니다. 잠긴 동안에는 올바른 비밀번호를 입력해도 접속할 수 없으며, 30분이 지나면 자동으로 잠금이 풀립니다. 기다리지 않고 바로 풀고 싶다면 비밀번호 재설정을 진행하면 됩니다. 재설정을 마치면 잠금이 즉시 해제됩니다. 하루 동안 잠금이 3번 발생하면 자동 해제가 되지 않고, 관리자 등급 사용자가 직접 잠금을 풀어 주어야 합니다. 잠금이 발생할 때마다 계정 이메일로 알림이 발송됩니다.

## 권한 등급

하늘창 계정에는 열람자, 관측자, 운영자, 관리자 네 가지 권한 등급이 있습니다. 열람자는 위성 통과 목록과 공개된 관측 결과만 볼 수 있습니다. 관측자는 열람자의 모든 기능에 더해 관측 예약, 변경, 취소를 할 수 있습니다. 운영자는 지상국 일정을 관리하고, 관측 시작 1시간 이내의 예약도 취소할 수 있습니다. 관리자는 사용자 권한 등급을 바꾸고 잠긴 계정을 해제할 수 있습니다. 새로 가입한 계정은 열람자 등급으로 시작하며, 관측자 이상으로 올리려면 관리자의 승인이 필요합니다.

## 2단계 인증

운영자와 관리자 등급 계정은 2단계 인증을 반드시 켜야 하며, 열람자와 관측자 등급은 선택 사항입니다. 2단계 인증을 켜면 비밀번호를 입력한 뒤 인증 앱에 표시되는 6자리 코드를 추가로 입력해야 합니다. 코드는 30초마다 바뀝니다. 인증 앱을 쓸 수 없는 상황에 대비해 처음 설정할 때 일회용 복구 코드 10개가 발급되며, 각 복구 코드는 한 번만 사용할 수 있습니다.
